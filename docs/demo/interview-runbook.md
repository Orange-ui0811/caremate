# CareMate：投屏操作台本

更新：2026-11-03。与[逐字稿](interview-presentation.md)配套，本文件仅本地保存。公开仓库提供[功能指南](https://github.com/Orange-ui0811/caremate/blob/main/docs/demo/README.md)，不发布口述稿。

## 提前准备

- 打开首页、图编排、LangChain模板、工具执行、Embedding、RAG、上下文报告七类页面；浏览器搜索定位函数名，避免依赖旧行号。
- 启动本地客服、MySQL、Milvus、两个MCP服务；Langfuse按需启动。登录独立演示账号，确认订单1001在本人列表。
- 每个案例使用新对话。阈值、校准、补库与分类器训练不在演示中临时运行。
- 已保存的记录注明时间；本次没有重新跑真实模型聊天，现场表现需事先彩排。核心逻辑测试结果见公开回归附件。
- 投屏不打开.env、Key管理页、个人历史对话。模型服务超时则展示实际错误及测试证据。

## 可选知识问答和库外问题

知识问答：`MH-LP100 的废砂盒多久倒一次？`，打开引用核对单猫5～7天、两只猫3～4天。库外问题：`你们卖活体宠物吗？`，先看实际路由；走“其他”只能证明固定引导，不能证明检索门控已执行。

## 每条演示留什么证据

记录代码版本、时间、模型、会话标识、输入、实际路由、工具参数和工具回执。真实模型记录与测试替身输出分别存放。工单取消不新增的数据库结论需要同会话前后查询；隔离测试仅证明创建函数没有被调用。
