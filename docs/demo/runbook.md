# 本地演示运行手册

## 准备

1. 按[部署说明](../../DEPLOY.md)配置模型、MySQL、Milvus，完成示例知识入库和向量化。不要在投屏中打开 .env 或模型池密钥配置。
2. 启动客服后打开 http://127.0.0.1:8000/；物流和售后 MCP 分别使用配置中的服务地址。Langfuse 单独启动，分类器服务按需准备。
3. 用独立演示会话核对订单 1001 是否在当前用户列表。每个核心场景使用新对话，避免历史影响路线。
4. 打开[功能清单](README.md)、[工具执行](../engineering/tool-execution.md)、[RAG 报告](../evaluation/rag/README.md)、[上下文报告](../evaluation/context/README.md)四个标签页。

## 建议操作顺序

| 场景 | 操作 | 需要展示的事实 | 异常处理 |
| --- | --- | --- | --- |
| 知识问答 | 输入产品维护问题并打开引用 | 条件、频率与证据一致 | 展示实际回答并回到知识原文核对 |
| 物流 | 输入订单 1001 查询 | 实际订单工具与 MCP 回执 | MCP 不可达时展示错误，不把模拟结果补成成功 |
| 选单 | 无订单号退货，点选本人订单 | 暂停、恢复、政策检索 | 没出现选单时检查意图与历史 |
| 工单取消 | 请求人工工单，预览后取消 | 写入执行受到确认控制 | 回归测试可验证调用是否发生 |
| 后台 | 打开观测与待审已有数据 | 当前阈值、统计样本、召回快照 | 不在展示中触发长耗时校准或审核写回 |
| Langfuse | 选择对应会话记录 | 模型/工具耗时与已上报用量 | 历史记录注明时间；无价格时只解释 Token |

## 无密钥核心回归

CI 通过占位环境变量满足配置校验；所有入选测试的模型、MCP、仓储操作由测试替身隔离。精确清单与环境见[CI 配置](../../.github/workflows/ci.yml)，实际运行结果见[回归记录](assets/core-tests-20261103.md)。本地在独立测试配置下运行同一清单，不连接生产数据库。

## 保存一次真实执行证据

记录代码 SHA、日期、模型名、输入、实际路由、工具参数、工具结果与会话标识；界面截图只保留演示对话。测试日志和真实模型 Trace 分开存放。当前公开附件是隔离测试记录，尚未附本次真实聊天截图或新运行 Trace。
