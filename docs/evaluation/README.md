# 实验与评估

本目录展示三组已完成的内部实验：RAG 四策略、五模型 Embedding 和上下文四方法。报告保留问题设计、统计分母、方法条件与限制，机器可读汇总由保存的实验产物提取。本次整理没有新增模型调用，也没有重跑并覆盖旧成绩。

| 实验 | 要回答的问题 | 规模 | 阅读入口 |
| --- | --- | --- | --- |
| RAG 四策略 | 向量、BM25、混合与重排分别怎样影响检索和回答？ | 300 题，240 道可答题用于主要质量指标 | [报告与五桶题目设计](rag/README.md) · [结果 JSON](rag/results.json) |
| 五模型 Embedding | 在同一知识与问题上，不同向量模型有什么取舍？ | 52 片段、300 题、5 模型 | [模型对比与输入协议](embedding/README.md) · [结果 JSON](embedding/results.json) |
| 上下文四方法 | 摘要、窗口与相关原文回查如何影响连续任务和模型用量？ | 同 24 段合成会话，每方法 72 次连续追问 | [四方法报告与问题设计](context/README.md) · [72 问目录](context/questions.json) · [结果 JSON](context/results.json) |

三组实验的日期、知识版本和执行链路不同，数值不能直接互相替代。RAG 测完整检索及生成的若干阶段；Embedding 仅测纯向量精确余弦排序；上下文测真实模型和 LangGraph/SSE，但检索、数据库与动态业务服务使用隔离夹具。

上下文页仅展示完整历史、仅滑动窗口、滚动摘要＋滑窗、滚动摘要＋滑窗＋新回查四种方法。它不是八组同期消融，也不把 pilot、失败重试或复用的对照另算独立样本。

## 指标阅读约定

- Recall@K 衡量所需证据组覆盖，不等于回答正确率；分组倒数排名与通常只看首个相关项的 MRR 不同。
- 答案要点覆盖使用模型裁判；机械证据要点匹配和模型裁判均不等于人工最终验收。
- 上下文“任务规则通过”与“三问全过”分别以 72 次追问和 24 段会话为分母；同一会话三问相关。
- Token 是模型上报的输入与输出用量。维护和重试按各实验声明入账；缺失 usage 标为下界，不按零计算，不直接换算货币成本。

本目录是报告展示包。提供汇总数据和合成题目设计，未包含完整私有运行目录、逐次模型输入输出、环境配置、凭据或所有历史源码快照；不将这些页面称为完整一键复现包。当前运行方案的结构说明见[上下文工程](../architecture/context-engineering.md)。
