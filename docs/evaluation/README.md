## 实验链路

| 实验 | 执行范围 |
| --- | --- |
| RAG | 对比检索排序、证据要点覆盖与生成答案要点覆盖 |
| Embedding | 文档与问题编码、向量归一化、精确余弦排序；采用模型对应的输入前缀与维度 |
| 上下文 | 真实模型和 LangGraph/SSE；数据库、知识检索与动态业务工具使用隔离夹具；各方法分别连续执行三次追问 |

## 指标定义

| 指标 | 统计对象 |
| --- | --- |
| 分组 Recall@K | 每题必需证据组在前 K 项中的覆盖比例，再对题目平均 |
| 分组倒数排名 | 各必需证据组首次命中排名的倒数，先组内、再题间平均 |
| 证据要点覆盖 | 检索文本对标准要点的字面覆盖 |
| 答案要点覆盖 | 模型裁判对生成答案覆盖标准要点的评价 |
| 上下文任务规则通过 | 72 次追问中满足对象、工具、事实与场景规则的次数 |
| 三问全部通过 | 24 段会话中三次连续追问均通过的段数 |
| 总 Token | 该工作负载记录到的模型输入与输出；维护、重试和缺失 usage 按报告说明计入 |

各实验独立记录数据版本、方法条件与运行日期。报告提供历史结果汇总和合成题目设计；原始逐次调用、完整预置历史与运行环境由各实验归档管理。源码与当前方案的对应关系见[架构文档](../architecture/README.md)。
