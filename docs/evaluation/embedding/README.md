# 五模型 Embedding 对比

实验日期：2026-10-22。固定 52 个知识片段、300 道题；A/B/C/E 各 60，共 240 道可答题计算质量指标，D 桶仅记录分数分布。五模型最终 API 运行均已完成。机器可读汇总见 [results.json](results.json)，输入协议见 [protocol.json](protocol.json)。

## 问题设计与控制条件

沿用 [RAG 五桶题集](../../../tests/data/eval_ch04.jsonl)：政策、型号、口语、库外和跨文档问题。具体例子与标注字段见 [RAG 问题设计](../rag/README.md#测试问题怎样设计)。各模型使用同一份冻结知识与问题；多证据题按每个必需证据组分别计分。

每个模型分别编码 52 个知识片段与 300 个问题。向量 L2 归一化后，在全部 52 个候选上计算精确余弦相似度，降序取 Top10。文档文本为 `category + 换行 + questions + 换行 + answer`。

这次比较不经过问题改写、拆分、BM25、RRF、重排或答案生成，也没有写入 Milvus/MySQL。它回答的是这份语料上的纯向量检索取舍，不是完整客服方案的最终排名。

| 模型 | 查询输入约定 | 最终维度 |
| --- | --- | ---: |
| BGE-M3 | 原问题 | 1024 |
| BGE-small-zh-v1.5 | 中文检索前缀＋原问题 | 512 |
| BGE-large-zh-v1.5 | 中文检索前缀＋原问题 | 1024 |
| Qwen3-Embedding-0.6B | 英文任务指令＋原问题 | 1024 |
| Qwen3-Embedding-4B | 英文任务指令＋原问题，显式请求 2560 维 | 2560 |

Qwen3-4B 最初默认返回 1024 维，维度探测后用显式 2560 维重跑，正式表只使用最终结果。模型使用各自的查询前缀与原生维度，没有强制为相同维度；API 的硬件、精度、分词和服务端截断不可独立观察。

## 总结果

| 模型 | 分组 Recall@5 | 分组倒数排名@10 | 证据要点覆盖@10 | 52 片段编码（秒） | 300 问题编码（秒） | 总编码（秒） |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| BGE-M3 | **98.96%** | 0.8444 | 99.79% | 3.84 | 17.17 | 21.02 |
| BGE-small-zh-v1.5 | 92.01% | 0.7391 | 96.88% | 2.02 | 10.35 | 12.37 |
| BGE-large-zh-v1.5 | 97.92% | 0.8511 | 100.00% | 2.35 | 13.06 | 15.42 |
| Qwen3-Embedding-0.6B | 97.99% | **0.8624** | 99.86% | 2.80 | 14.38 | 17.18 |
| Qwen3-Embedding-4B | 97.64% | 0.8468 | 99.65% | 4.04 | 19.10 | 23.14 |

M3 在这份题集的 Recall@5 较高，Qwen0.6B 的分组排名较高；不同指标并不产生同一个胜者。较大模型也没有在所有桶上更好。

## 指标、耗时与审计

分组 Recall@5、分组倒数排名@10 均先对必需证据组计算，再对题目平均；未在前十命中的组倒数排名记零。证据覆盖是前十条文本中标准要点的字面匹配比例，不是答案覆盖或幻觉率。

每模型 352 条文本、45 个批次，batch size 为 8；模型依次串行运行，无预热、仅一轮。表中时间包含网络、排队、推理、解析及可能的重试，不含向量检索计算。时间采用批量 API 编码总耗时口径，单请求延迟与纯计算时间未单独测量。

保存的向量已离线复算全部模型的指标与排名；另有 500 组指标函数一致性检查。与 M3 的配对分层 bootstrap 统计此内部题集的抽样变化。结果 JSON 保留逐桶指标，原运行向量与技术日志保存在实验归档中。

评估范围为 52 条候选的小规模内部知识库，Top10 占候选量约 19.2%。本实验测量向量检索质量与 API 编码耗时；大型知识库、跨领域检索及答案生成质量另行评估。
