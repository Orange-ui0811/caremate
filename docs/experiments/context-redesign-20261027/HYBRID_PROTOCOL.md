## 冻结策略

- L / legacy：原默认摘要、30条消息触发、保留8轮、原有节点截取和Token限制。
- S6 / summary6：原摘要提示词和后台维护逻辑；未摘要消息达到30条触发，摘要后留6轮；所有未摘要原文完整进入各节点，不按Token裁剪。
- H6 / hybrid6：与S6相同，另外用当前问题对已摘要的旧用户原话做BM25。中文双字词项；取正分前三，同分优先较新；返回整轮用户/助手原文，每个命中补下一轮（仅限旧历史）。去重，最多六轮旧问答，按时间排列，不做实体递归扩展，不按Token裁剪。

新两组不设置本地Token准入上限；仍记录实际请求估算和供应商usage，供应商拒绝或超长错误如实保留。旧两组保持其原限制。所有组相同模型、关闭思考、原温度、8192输出上限和共同业务执行规则。不能称为四组同预算实验。

未摘要原文正常为6～14轮，达到15轮触发。正常一问一答且维护及时成功时，首次第15轮、随后第24/33轮维护。旧摘要与新滑出原文合并为一份摘要；既不分层也不分段。失败维持旧摘要和边界，下轮可按原生产机制重触发。

S6与H6的摘要独立生成，种子与后续回复都按组独立演进。随机摘要差异会影响对比；逐项审查不能把摘要偶然差异一律归因于BM25。此前35/36不直接转记为本轮结果。
