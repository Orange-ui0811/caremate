# 保留3轮：五种上下文方法对照（运行前协议）

目的：比较客服上下文的任务效果和完整模型成本，检验摘要与原文回查的互补性。不得依据正式结果修改问题、提示词、评分或回查算法；不得删除语义错误。生产配置不在本实验中切换。

## 方法与共同条件

|方法|早期摘要|早期原文回查|近期原文|
|---|---|---|---|
|完整历史|无|无|使用历史的节点携带全部可见原问答|
|仅滑动窗口|无|无|批次滑窗|
|滚动摘要＋滑窗|原项目滚动摘要|无|批次滑窗|
|相关原文检索＋近期窗口|无|BM25|批次滑窗|
|滚动摘要＋滑窗＋原文回查|原项目滚动摘要|BM25|批次滑窗|

四个紧凑组共用窗口更新规则：边界之后累计30条消息，更新后留下最近3轮。无摘要组仅在本地推进同样的边界，不调用摘要模型。常规一问一答时，首次第15轮更新，此后第27、39轮；未归档区通常为3～14轮，并非每轮固定3轮。摘要失败不推进边界，因此实测中各组边界可能不同，必须保留并解释。

摘要仍为“旧摘要＋本次滑出原文→新摘要”，使用原提示词、结构化输出和重试方式，不增设分层摘要或摘要长度策略。生产在回复后后台维护；实验等待维护结束，以确定下一轮状态并完整记账，故实验端到端耗时不是生产客服延迟。

沿用节点原有输入方式：指代消解和意图识别取窗口末尾6条消息并附摘要；回答节点保留原3000估算Token窗口、固定系统提示及当前工具消息；查询改写仍只接收消解后的问题。回查仅在这些原有历史位置附加旧问答，不为每个节点重复注入整段近期历史。完整历史组仅取消历史截断，共同查询改写协议不变；不额外设置完整请求输入上限或静默截短。

回查范围是已归档/已退休的原文前缀，索引用户原话，中文双字片段及英文/编号参与BM25；取正分Top3，每个匹配带紧邻的下一旧问答，去重后最多6个问答单元，按时间排列。返回完整单元和消息位置/hash，不引入额外模型规划。纯指代可能无匹配；跨多轮更正也未必被相邻扩展覆盖。归档边界之后、节点最近6条消息之前还有可见性盲区，本轮包含对应诊断样例。

所有组固定当前Gitee模型、关闭思考、共同温度/输出限制/业务工具及权限检查。隔离数据库、知识检索和业务工具采用合成夹具；真实LangGraph、模型调用、指代消解、意图、检索决策、回答、SSE路径参与运行。模型池不跨供应商故障转移。固定PYTHONHASHSEED=0，避免BM25浮点累加顺序变化。

## 数据、执行和评分

正式24会话×3次实际追问×5组＝360轮，每会话每组一次运行。16条已见回归和8条新内部合成样例分开报告；新样例不是独立外部测试集。新增普通明确查询、窗口中间区关系、非相邻更正、别称、纯指代、限制撤回、歧义。运行前同时冻结数据、金标、模型配置、提示词和源码，另用独立预检案例排除接线错误。无额外语义重跑或挑选最好结果。

最多两个独立进程运行互斥会话分片，各进程内五组依次执行并轮换顺序；每片独立记录目录和调用ID。不得在同一进程并发修改节点补丁或并发写同一个结果目录。保留分片和日志，结束后逐文件校验并合并；报告文件存在不能代替完成核验。

|指标|固定口径|
|---|---|
|多轮任务完成|每组72次追问，复用冻结规则核查目标、动作、检索、回答，接口失败仍占主指标分母，另列失败类别|
|更正处理|逐追问标签预声明10轮，检查目标查询及任务通过，不将后续无更正轮混入|
|限制处理|9轮只读限制，报告正确目标及无写操作提议/执行；不代表完整限制状态核验，也不测试正向写授权|
|歧义澄清|4个金标clarify问题，核查应澄清且没有猜测查询；该会话的后续明确选择不混入分母|
|全输入/输出Token|全部模型调用，包括初始化摘要、三次追问、回复后维护、结构化输出重试；缺失usage记未知/已知下界，不能当0|
|整段会话通过|每组24段，三次追问全部通过才通过；预置历史不是模型现场生成，也不计入该成功率|

同时分层报告长短、已见/新增、首次/后续追问，配对列出本方案对每个参照的独赢/独输。连续追问相关，有错误传播，不把360轮当360个独立会话。评分是任务规则通过率，关键词和正则不足以证明完整事实正确率，最终人工检查关键胜负案例。

## 成本及结论边界

所有输入/输出均以供应商实际usage为主，账本包括当前工作负载内所有维护及重试。预置历史的生成成本、真实向量检索和业务系统费用不在本实验范围；不能把此账本称为真实完整客户生命周期成本。模型池重试没有逐attempt usage时独立提示未知，不能推算为精确费用。

合并后运行通用账本/评分审计、独立来源/摘要/窗口复算、指标分析。独立审计核查源码快照、未来信息隔离、摘要来源、全历史完整性、回查只追加不改变原节点输入、30/keep3边界、失败时边界不推进。最终只报告被记录支持的效果和成本，不预设三组件方案必胜；单次内部合成对照不能外推为线上准确率或统计显著提升。
